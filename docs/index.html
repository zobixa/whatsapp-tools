How it works

You need Node.js 18+ and a WhatsApp account to pair (a spare number is recommended — see the honest notes below).

1

Download & install

Download the ZIP from GitHub, unzip it, and run one install command. Takes about a minute.

2

Pair your WhatsApp

The first run shows a QR code in your terminal. Scan it with WhatsApp > Linked Devices, exactly like WhatsApp Web. You only scan once.

3

Run it on any shop

Give it a number or a wa.me/c/ catalog link. It fetches the whole catalog, page by page, and writes your CSV.

npm install
npm start -- 919876543210
# or: npm start -- "https://wa.me/c/919876543210"
# result: catalog-919876543210.csv

What you get in the CSV

One row per product, ready to open in Excel or Google Sheets (the file is UTF-8, so prices, emoji and non-English names show correctly).

ColumnWhat it is
name, descriptionProduct title and full description text

sku_retailer_idThe shop's own SKU / retailer ID, if they set one
image_urlDirect link to the product image
product_urlThe product's shareable wa.me/p/ link
availability, collectionStock status and which catalog collection the product belongs to

The honest notes (read before you run it)

WhatsApp has no public, no-login catalog API — that's why this tool pairs with your WhatsApp instead of working as an instant online form, and why you should be suspicious of sites that promise otherwise. It uses an unofficial client (Baileys), which is against WhatsApp's terms: low-volume use is usually fine, but the paired number can get banned, so pair a spare number, not your main one. Only export catalogs you have a legitimate reason to use, and respect the shop owner's rights in their product data and images. Exporting your own catalog? The tool also includes an official Meta Graph API mode with no pairing and no ban risk.

FAQ

How do I export a WhatsApp catalog to CSV?

Download the free tool from GitHub, run npm install, then run it with the shop's number or wa.me/c/ link. Scan the QR code once with your WhatsApp, and it saves the whole catalog as a CSV file.

Can I export someone else's WhatsApp catalog?

Yes, if the catalog is public. WhatsApp Business catalogs are made to be browsed by customers, and this tool reads them the same way the WhatsApp app does, after you pair your own WhatsApp.

Is there an online version that works without installing anything?

No honest one. WhatsApp has no public no-login catalog API, so any site promising instant exports is running paired WhatsApp accounts behind the scenes. This tool runs on your own machine with your own login instead.

Is this tool free?

Yes. It's open source under the MIT license on GitHub — no accounts, no limits, no paid tiers.

Can my WhatsApp number get banned for using it?

The tool uses an unofficial client (Baileys), which is against WhatsApp's terms. Low-volume use is usually fine, but a ban is possible, so pair a spare number rather than your main one.
